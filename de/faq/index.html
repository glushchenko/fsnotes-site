Häufig gestellte Fragen

1. Wo sind meine Notizen? Nach dem Start ist die Bibliothek leer.

FSNotes arbeitet direkt mit den Ordnern, die Sie auswählen, und speichert keine separate versteckte Kopie Ihrer Notizen. Wenn die App eine leere Bibliothek zeigt, befinden sich Ihre Dateien normalerweise weiterhin an ihrem ursprünglichen Speicherort.

Prüfen Sie zuerst, ob in FSNotes der richtige Speicherordner ausgewählt ist. Liegt der Ordner in iCloud Drive, stellen Sie sicher, dass die Dateien auf das Gerät geladen wurden. Befindet er sich auf einem externen Laufwerk, verbinden Sie das Laufwerk erneut und öffnen Sie FSNotes noch einmal.

Für wichtige Notizen empfehlen wir ein zusätzliches Backup. FSNotes kann Git-basierte Sicherungen erstellen, diese Funktion muss jedoch vorher eingerichtet werden.

2. FSNotes startet nicht. Was kann ich tun?

Das tut uns leid. Eine sehr große Bibliothek oder eine problematische Datei kann in seltenen Fällen verhindern, dass FSNotes normal startet.

Verschieben Sie den Inhalt Ihres Speicherordners vorübergehend an einen anderen Ort und starten Sie FSNotes erneut. Wenn die App nun geöffnet wird, kopieren Sie die Notizen in kleineren Gruppen zurück, um die verursachende Datei oder den Ordner zu finden. Sie können außerdem versuchen, die FSNotes-Einstellungen zurückzusetzen.

Falls das Problem weiterhin auftritt, erstellen Sie bitte ein Issue auf GitHub. Geben Sie dabei Ihre FSNotes-Version, die Version des Betriebssystems und eine kurze Beschreibung des Startverhaltens an.

3. Kehren RTF-Unterstützung und die horizontale Notizenliste zurück?

FSNotes 7 konzentriert sich auf Arbeitsabläufe mit reinem Text und Markdown. Die aktuelle Anordnung der Notizenliste ist Teil dieser Ausrichtung. Eine Rückkehr von RTF und der horizontalen Notizenliste ist derzeit nicht geplant.

Wir verstehen, dass einige langjährige Nutzer den früheren Arbeitsablauf bevorzugen. Feedback ist willkommen, wir können jedoch nicht versprechen, dass jede Funktion aus älteren Hauptversionen zurückkehrt.

4. Ich wünsche mir eine neue Funktion. Wann wird sie hinzugefügt?

FSNotes wird von einem kleinen Team gepflegt. Stabilität, Leistung und vorhandene Funktionen haben deshalb meist Vorrang vor einer Erweiterung der Roadmap. Wir lesen Funktionswünsche, können aber nicht versprechen, ob oder wann eine bestimmte Idee umgesetzt wird.

Der beste Ort für Vorschläge sind die GitHub Discussions. FSNotes ist Open Source, daher sind gut getestete Pull Requests ebenfalls willkommen. Sie können das Projekt auch forken und an Ihren eigenen Arbeitsablauf anpassen.

5. Ich habe eine Idee. Wo kann ich sie teilen?

Teilen Sie Produktideen bitte in den GitHub Discussions. Für allgemeine Fragen und Gespräche können Sie auch der FSNotes-Gruppe auf Telegram beitreten.

Wir lesen und berücksichtigen jedes Feedback, auch wenn eine persönliche Antwort nicht immer möglich ist. Vielen Dank, dass Sie helfen, FSNotes zu verbessern.

6. Unterstützt FSNotes alle iPad-Funktionen?

Die aktuelle iPad-Version erhält keine speziell für das iPad entwickelten Funktionen wie vollständige Tastaturkurzbefehle oder Mehrfensterunterstützung. Die Entwicklung konzentriert sich derzeit auf macOS und iPhone.

Die vorhandene iPad-Version bleibt im App Store verfügbar. Prüfen Sie bitte vor dem Kauf, ob ihr aktueller Funktionsumfang zu Ihren Anforderungen passt.
