FSNotes is a fast, native Markdown notes app for Mac built for people who want simple files instead of another proprietary notes database. It works directly with folders on your Mac, supports GitHub Flavored Markdown, and stays responsive across collections containing thousands of notes.

## Your notes remain ordinary files

Every note is stored in an open format you can inspect, copy, back up, and edit with other tools. You are not required to export your library before switching applications, and your writing remains readable even if FSNotes is not installed.

This file-based approach works especially well for developers, researchers, writers, and anyone who already organizes projects with folders and Markdown.

## Native macOS performance

FSNotes is designed for macOS rather than wrapped in a browser runtime. Search, navigation, editing, and keyboard shortcuts feel at home on a Mac. The app can work smoothly with libraries containing more than 10,000 files and supports multiple storage folders.

The two-pane interface keeps the note list and editor visible without turning note-taking into a complex workspace. Dark mode, pinned notes, tags, syntax highlighting, MathJax, Mermaid diagrams, and inline images are available when you need them.

## Search, links, and organization

Instant search helps locate notes by title or content. Organize material with normal folders and tags, then create connections between notes using `[[wiki links]]`.

Because FSNotes works with your existing directory structure, the same files can also be searched by Spotlight, versioned with external Git tools, or opened in another Markdown editor.

## Sync with iPhone and back up with Git

iCloud Drive can keep your Markdown library synchronized between Mac and iPhone. FSNotes also includes optional Git integration for scheduled commits, history, push, and pull.

Sync and backup solve different problems: iCloud keeps devices current, while Git gives you an additional history of changes. Important files should still be included in your regular backup strategy.

## Open source, with no subscription

FSNotes is [open source on GitHub](https://github.com/glushchenko/fsnotes). You can inspect the code, download the app for free, or purchase it from the Mac App Store to support continued development and receive convenient updates.

There is no required account and no recurring subscription.
