FSNotes 是一款快速、原生的 Mac Markdown 笔记应用，适合希望使用普通文件，而不是把内容存进另一个专有数据库的用户。它直接使用 Mac 上的文件夹，支持 GitHub Flavored Markdown，并能在包含数千条笔记的资料库中保持流畅。

## 笔记始终是普通文件

每条笔记都使用开放格式保存，您可以查看、复制、备份，也可以用其他工具编辑。更换应用前无需导出整个资料库；即使没有安装 FSNotes，笔记仍然可以读取。

这种基于文件的方式特别适合开发者、研究人员、写作者，以及已经使用文件夹和 Markdown 整理项目的用户。

## 原生 macOS 性能

FSNotes 专为 macOS 开发，而不是运行在封装的浏览器环境中。搜索、导航、编辑和键盘快捷键都符合 Mac 的使用习惯。应用可以流畅管理超过 10,000 个文件，并支持多个存储文件夹。

双栏界面同时展示笔记列表和编辑器，不会把简单记录变成复杂工作区。深色模式、置顶笔记、标签、语法高亮、MathJax、Mermaid 图表和内嵌图片都可以按需使用。

## 搜索、链接与整理

即时搜索可以按标题或内容查找笔记。使用普通文件夹和标签整理资料，并通过 `[[双向链接]]` 连接相关笔记。

由于 FSNotes 保留现有目录结构，同一批文件也可以通过 Spotlight 搜索、使用外部 Git 工具管理版本，或在其他 Markdown 编辑器中打开。

## 与 iPhone 同步，并使用 Git 备份

iCloud Drive 可以让 Mac 和 iPhone 上的 Markdown 资料库保持同步。FSNotes 还提供可选的 Git 集成，支持自动提交、历史记录、Push 和 Pull。

同步和备份解决的是不同问题：iCloud 让设备保持最新状态，Git 则提供额外的修改历史。重要文件仍应包含在您的常规备份方案中。

## 开源且无需订阅

FSNotes 在 [GitHub 上开源](https://github.com/glushchenko/fsnotes)。您可以查看源代码、免费下载应用，也可以在 Mac App Store 购买，以支持持续开发并方便地接收更新。

无需强制账户，也没有周期性订阅。
