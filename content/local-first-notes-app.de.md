Eine Local-first Notizen-App behandelt die Dateien auf Ihrem Gerät als primäre Kopie Ihrer Daten. FSNotes folgt diesem Modell: Ihre Notizen liegen in Ordnern, die Sie auswählen, bleiben offline verfügbar und lassen sich ohne FSNotes-Konto oder verpflichtenden Onlinedienst öffnen.

## Was Local-first bei FSNotes bedeutet

FSNotes liest und schreibt reine Markdown- und TextBundle-Dateien direkt. Es gibt keinen vorgeschriebenen Import und keine versteckte Cloud-Datenbank, die als einzige Quelle Ihrer Daten dient.

Auch ohne Internet können Sie die auf Ihrem Gerät gespeicherten Dateien lesen, durchsuchen und bearbeiten. Wenn Sie später einen anderen Markdown-Editor verwenden möchten, bleiben dieselben Notizen verfügbar.

## Kontrolle über Dateien ohne Verzicht auf Komfort

Local-first bedeutet nicht, dass jedes Gerät isoliert bleiben muss. Sie können einen FSNotes-Speicherordner in iCloud Drive ablegen und zwischen Mac und iPhone synchronisieren. Der Unterschied: Die Synchronisierung arbeitet mit Dateien, die Sie kontrollieren, statt sie durch eine unzugängliche Dienstdatenbank zu ersetzen.

Sie können mehrere Ordner verwalten, ausgewählte Projekte außerhalb von iCloud speichern und externe Editoren parallel zu FSNotes verwenden.

## Synchronisierung ist kein Backup

Eine Synchronisierung überträgt Änderungen schnell auf verbundene Geräte – auch versehentliche Änderungen. Ein Backup bewahrt einen unabhängigen Verlauf, aus dem sich eine frühere Version wiederherstellen lässt.

FSNotes bietet eine optionale Git-Integration für automatische Commits, Push, Pull und Dateiverlauf. Für zusätzlichen Schutz können Sie diese mit Time Machine oder einem anderen Backup-System kombinieren.

## Datenschutz und Verschlüsselung

FSNotes benötigt kein Konto, um eine lokale Bibliothek zu öffnen. Vertrauliche Notizen oder Ordner können mit AES-256 verschlüsselt und auf unterstützten Geräten per Touch ID entsperrt werden.

Verschlüsselung schützt sensible Inhalte, ersetzt jedoch kein Backup. Bewahren Sie Wiederherstellungsinformationen und unabhängige Kopien wichtiger Dateien an einem sicheren Ort auf.

## Für wen eignet sich eine Local-first Notizen-App?

FSNotes passt besonders gut, wenn Sie:

- Notizen als normale Dateien speichern möchten;
- offline oder bei unzuverlässiger Internetverbindung arbeiten;
- offene Formate proprietären Datenbanken vorziehen;
- Git oder externe Texteditoren verwenden;
- iCloud-Synchronisierung ohne monatliches Abonnement möchten;
- eine native Markdown-Notizen-App für das Apple-Ökosystem suchen.
