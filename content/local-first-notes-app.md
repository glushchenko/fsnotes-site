A local-first notes app treats the files on your device as the primary copy of your data. FSNotes follows this model: your notes live in folders you choose, remain available offline, and can be opened without depending on an FSNotes account or hosted service.

## What local-first means in FSNotes

FSNotes reads and writes plain Markdown and TextBundle files directly. There is no mandatory import process and no hidden cloud database acting as the only source of truth.

If the internet is unavailable, you can continue reading, searching, and editing the files already stored on your device. If you decide to use a different Markdown editor later, the same notes remain available.

## File ownership without giving up convenience

Local-first does not mean that every device must stay isolated. You can place an FSNotes storage folder in iCloud Drive to synchronize it between Mac and iPhone. The difference is that synchronization works with files you control rather than replacing them with an inaccessible service database.

You can also maintain multiple folders, keep selected projects outside iCloud, and use external editors alongside FSNotes.

## Sync is not a backup

Synchronization quickly copies changes—including accidental changes—to connected devices. A backup keeps an independent history that can help recover an earlier version.

FSNotes offers optional Git integration for scheduled commits, push, pull, and file history. You can combine it with Time Machine or another backup system for additional protection.

## Privacy and encryption

FSNotes does not require an account to open a local library. Sensitive notes or folders can be protected with AES-256 encryption and unlocked with Touch ID on supported devices.

Encryption is useful for confidential material, but it does not replace backups. Keep recovery information and independent copies of important files in a safe place.

## Who benefits from a local-first notes app?

FSNotes is a strong fit if you:

- want notes stored as normal files;
- work offline or in unreliable network conditions;
- prefer open formats over proprietary databases;
- use Git or external text editors;
- want iCloud synchronization without a monthly subscription;
- need a native Markdown notes app for the Apple ecosystem.
