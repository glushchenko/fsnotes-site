本地优先笔记应用

本地优先笔记应用会把设备上的文件视为数据的主要副本。FSNotes 遵循这一模式：笔记位于您选择的文件夹中，可以离线访问，也不依赖 FSNotes 账户或托管服务才能打开。

FSNotes 中的“本地优先”意味着什么

FSNotes 直接读写 Markdown 和 TextBundle 文件。没有强制导入流程，也没有隐藏的云端数据库作为数据的唯一来源。

即使没有网络，您仍然可以阅读、搜索和编辑设备上已有的文件。如果以后决定使用其他 Markdown 编辑器，同一批笔记依然可用。

掌控文件，同时保留便利性

本地优先并不意味着所有设备必须彼此隔离。您可以把 FSNotes 存储文件夹放在 iCloud Drive 中，在 Mac 和 iPhone 之间同步。区别在于：同步处理的是您可以掌控的文件，而不是用无法直接访问的服务数据库替代它们。

您还可以管理多个文件夹，把部分项目保存在 iCloud 之外，并与 FSNotes 同时使用外部编辑器。

同步不等于备份

同步会迅速把修改复制到其他设备，包括误操作。备份则保留独立历史，帮助您恢复之前的版本。

FSNotes 提供可选的 Git 集成，支持自动提交、Push、Pull 和文件历史。还可以结合 Time Machine 或其他备份系统，获得额外保护。

隐私与加密

打开本地资料库不需要 FSNotes 账户。敏感笔记或文件夹可以使用 AES-256 加密，并在支持的设备上通过 Touch ID 解锁。

加密可以保护机密内容，但不能替代备份。请妥善保存恢复信息，并为重要文件保留独立副本。

谁适合使用本地优先笔记应用？

如果您有以下需求，FSNotes 会非常适合：

  • 希望笔记以普通文件保存；
  • 经常离线工作或网络不稳定；
  • 更信任开放格式，而不是专有数据库；
  • 使用 Git 或外部文本编辑器；
  • 希望使用 iCloud 同步，但不想支付月度订阅；
  • 需要 Apple 生态中的原生 Markdown 笔记应用。
