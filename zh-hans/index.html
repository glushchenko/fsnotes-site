Mac 和 iPhone 上的快速 Markdown 笔记

FSNotes 是一款围绕您自己文件构建的原生笔记应用。使用 GitHub Flavored Markdown 写作，轻松管理数千条笔记，通过 iCloud 同步，并在没有网络时继续工作。

FSNotes 是开源软件。可从 App Store 获取支持自动更新的官方稳定版本。

为什么选择 FSNotes

让笔记始终由您掌控

FSNotes 将快速、原生的 Apple 平台体验与持久的开放格式结合在一起。无需创建账户，也不会把您的内容锁在专有数据库中。

纯 Markdown 文件

使用 FSNotes、文本编辑器或任何其他 Markdown 应用打开笔记。即使不再使用 FSNotes，文件仍然可以正常阅读。

原生且快速

专为 macOS 和 iOS 构建，支持键盘操作、即时搜索，并能流畅处理超过 10,000 个文件的资料库。

通过 iCloud 同步

使用 iCloud Drive，让 Mac 和 iPhone 访问相同的文件夹与笔记。

Git 备份

自动创建提交、查看笔记历史，并可选择向远程 Git 仓库推送或拉取更改。

需要时保护隐私

使用 AES-256 加密单条笔记或整个文件夹，并在支持的设备上通过 Touch ID 解锁。

链接、标签与文件夹

通过 [[双向链接]] 建立知识关联，使用标签整理内容，并保留现有文件夹结构。

本地优先设计

拥有自己的文件，而不是租用数据库

FSNotes 直接使用设备上的文件夹。无需强制账户、指定云服务或订阅。您可以按照自己的方式备份文件，也可以随时更换编辑器。

图片和附件可以与文本一起保存在 TextBundle 容器中。

管理大型笔记库所需的一切

  • Markdown 优先：支持纯文本文件。
  • 快速轻量：流畅处理超过 10,000 个文件。
  • 随处访问：通过 iCloud Drive 同步。
  • 多文件夹存储。
  • 键盘优先：受 Notational Velocity 启发的操作方式。
  • 支持 30 多种编程语言的语法高亮。
  • 支持内嵌图片。
  • 使用标签整理笔记。
  • 使用 [[双括号]] 创建笔记链接。
  • 灵活的双栏视图。
  • 支持外部编辑器并实时刷新。
  • 置顶重要笔记。
  • 快速复制笔记到剪贴板。
  • 深色模式。
  • 使用 AES-256 保护敏感内容。
  • 支持 Mermaid 和 MathJax。
  • 可选的 Git 版本管理与备份。
  • 使用 TextBundle 保存带附件的笔记。
  • 在受支持的 Mac 上使用 Touch Bar 编辑。

一次性购买

永远无需订阅

FSNotes 是开源软件，源代码可在 GitHub 免费获取。您可以从 App Store 获取支持自动更新的官方 Mac 和 iPhone 应用。每次购买都有助于支持项目的持续开发。

随时记录

iPhone 版 FSNotes

在 Mac 和 iPhone 上使用相同的 Markdown 文件和熟悉的整理方式。

  • 通过 iCloud Drive 同步。
  • 支持 TextBundle 与加密 TextBundle。
  • 置顶笔记在设备间保持同步。
  • 支持动态字体。
  • 可根据位置或屏幕亮度切换深色模式。
  • 提供分享扩展。
  • 支持加密笔记和文件夹。
  • 提供深入的 Git 集成。
  • 使用标签整理内容。
  • 将笔记发布为网页。

同步兼容性：FSNotes iOS 版目前支持 iCloud Drive，不支持 Dropbox、WebDAV 或 Google Drive 同步。
